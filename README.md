## Descripción del Proyecto
Este repositorio contiene el desarrollo del Laboratorio 01, donde se aplican los conceptos fundamentales de Dart: variables, tipos de datos, operadores, funciones y entrada/salida de datos por terminal.

El proyecto incluye dos programas principales (Retos integradores):
1. **AgroDiversa (`agricultural_observation.dart`):** Un sistema de consola para capturar datos de cultivos agrícolas, calcular el área total, los promedios y el porcentaje de participación de cada cultivo en una región específica.
2. **Presupuesto de Excursión (`excursion_budget.dart`):** Una calculadora financiera que determina los costos totales de alojamiento, alimentación, transporte y el costo individual por viajero para un grupo turístico.

## Requisitos de Ejecución
- Tener instalado el **Dart SDK** en el sistema operativo.
- Una terminal o consola de comandos.

## Comandos Necesarios
Para ejecutar los programas, abre la terminal en la raíz del proyecto y utiliza los siguientes comandos:
